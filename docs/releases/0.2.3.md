Что нового в 0.2.3 (изменения после 0.2.1):

iPhone — первый выпуск
- egl-viewer для iPhone на том же ядре, что и десктоп, с теми же библиотеками `.eglib`. Eagle на телефоне нет.
- Библиотеки: создание в «На iPhone», открытие из «Файлов». Библиотека из iCloud Drive открывается только для чтения.
- Просмотр: папки, смарт-папки, теги, сетка и список, сортировка, поиск, фильтры, выделение всего вида. Полноэкранный просмотр с увеличением и детали элемента.
- Правки: рейтинг, теги, папки, корзина и отмена. Сохранение оригиналов и «Поделиться».
- Добавление из «Фото» (HEIC сохраняется как есть), «Файлов», буфера обмена и перетаскиванием, с вопросом о дубликатах.
- Папки, группы тегов, редактор смарт-папок.
- Запертые папки: снова запираются, когда приложение уходит с экрана. Вход в приложение по паролю или Face ID.
- Настройки: резервные копии и восстановление, проверка и исправление библиотеки, пересборка миниатюр, экспорт в ZIP (можно с паролем) или в папку.
- Интерфейс на английском, русском и китайском, светлая и тёмная тема.
- IPA не подписан: при установке подпишите его своим Apple ID (AltStore, SideStore, Sideloadly или Xcode).

Формат библиотеки 6
- Id из экспорта в Eagle хранятся отдельно от id импорта из Eagle: повторный импорт больше не путается после экспорта в другую библиотеку Eagle.
- Библиотека обновляется при первом открытии, перед этим автоматически делается резервная копия. После обновления 0.2.1 и старше её не откроют: обновите все свои устройства.

Исправления
- При подключённом Eagle правка элемента, групповая правка и отпирание папки больше не подвешивают приложение.
- Открытие или создание своей библиотеки завершает подключение к Eagle. Токен сохраняется только после успешного подключения.
- «Отключиться» останавливает идущее добавление в Eagle. Неудачное добавление показывает ошибки, а не «Отменено».
- Экспорт в Eagle сохраняет уже созданное при любой остановке и не держит расшифрованные оригиналы после работы. К одному Eagle идёт не больше двух запросов одновременно.
- Импорт из папки Eagle записывает миниатюры, не путает PNG-оригинал с его миниатюрой и прерывается при ошибке диска, а не продолжает с пропусками.
- Запертые папки: ключ восстановления всегда выдаётся; папкам, импортированным запертыми без пароля, можно задать первый пароль.
- Экспорт удаляет недописанный результат при ошибке и не пишет внутрь библиотеки Eagle или egl-viewer.
- Нечитаемый файл входа больше не отключает вход в приложение.
- Диалог экспорта не теряет прогресс и подхватывает идущий экспорт. Отдельный вопрос при выходе во время экспорта.
- Выделение восстанавливается и для вида по умолчанию. Русские формы множественного числа исправлены.
